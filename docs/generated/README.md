<a id="rules"></a>
## Rules

- Do not edit these files. Change the source, then run `php tools/gaia-dev/bin/gaia-dev graph export` and `php tools/gaia-dev/bin/gaia-dev docs generate`.
- CI fails when either is stale (`graph export --check`, `docs generate --check`).
- Every section has a stable anchor (`<a id="...">`) and at most 40 lines.
- Hand-written reasons live in `docs/architecture/*/decisions.md`; `gaia-dev` tests check what they cite.
